[#scope-functions]
=== Functions

[#get-scope-identifier]
==== `getScopeIdentifier()`

Gets the scope identifier based on the application context.

[source,ts]
----
getScopeIdentifier(
  appStateService: AppStateService,
  skipStyleScoping?: boolean | null,
  remoteComponentConfig?: ReplaySubject<RemoteComponentConfig> | null
): Promise<string>
----

* For **Shell**: Returns empty string (no scoping)
* For **RCs**: Uses `remoteComponentConfig` to build scope ID from product name and app ID
* For **MFEs**: Uses `currentMfe$` topic to build scope ID

[#scope-primeng-css]
==== `scopePrimengCss()`

Wraps PrimeNG CSS in `@scope` rules. For browsers without native `@scope` support, wraps in `@supports` instead.

[source,ts]
----
scopePrimengCss(css: string, scopeId: string): string
----

[#replace-primeng-prefix]
==== `replacePrimengPrefix()`

Replaces `--p-` prefix in CSS with a scope-specific prefix.

[source,ts]
----
replacePrimengPrefix(css: string, scopeId: string): string
----

[#scope-identifier-to-variable-prefix]
==== `scopeIdentifierToVariablePrefix()`

Converts a scope ID to a CSS variable prefix.

[source,ts]
----
scopeIdentifierToVariablePrefix(scopeId: string): string
----

Example: `"onecx-workspace|onecx-workspace-ui"` → `"--onecx-workspace-onecx-workspace-ui-"`

[#scope-id-from-product-name-and-app-id]
==== `scopeIdFromProductNameAndAppId()`

Builds a scope ID from product name and application ID.

[source,ts]
----
scopeIdFromProductNameAndAppId(productName: string, appId: string): string
----

Example: `"onecx-workspace"`, `"onecx-workspace-ui"` → `"onecx-workspace|onecx-workspace-ui"`

[#provide-app-styles-initializer]
=== `provideAppStylesInitializer()`

Provides an environment initializer that runs during application startup to update application styles with scoped PrimeNG variable prefixes.

[source,ts]
----
provideAppStylesInitializer(): EnvironmentProvider[]
----

The initializer:

1. Resolves the application's scope ID
2. Finds the application's style element via `getAppStyleByScope()`
3. Replaces all `--p-` references in the stylesheet with the scoped prefix using `replacePrimengPrefix()`
4. Updates the element's content via `replaceStyleContent()`
